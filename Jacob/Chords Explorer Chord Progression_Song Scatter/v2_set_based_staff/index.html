Chordonomicon + Spotify

Which songs use these chords?

Pull base chords up from the lower staff to the upper staff. The songs that use all of them pop up on the timeline below; until you pick a chord it stays empty, and the genre buttons narrow it to one genre. A base chord is the chord's root, so C covers C, Cmaj7, C/E and so on.

Click a note on the lower staff to move it to the upper staff.

Loading songs…

Data is read straight from chordonomicon_spotifydump_join.csv.gz in the Chords-Explorer folder (decompressed in your browser). Each dot is one song, placed by release date, sized by Spotify popularity and colored by main genre; vertical position is random. Sharps and flats are merged (F♯ = G♭), seventh and slash chords count as their root, songs without a release date or from before 1950 are left out.
